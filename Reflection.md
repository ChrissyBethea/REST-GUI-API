Module 3 Assignment 2 – Reflection
For this assignment, I created a desktop application using Tkinter and connected it to a Flask API. I started by creating a form that collects purchase information, including a product ID, description, customer name, email address, price, and purchase type. I then added validation to make sure the email address was formatted correctly and the price did not exceed $1,000.
One challenge I experienced was getting the GUI to communicate with the Flask API. I had to troubleshoot the connection and make sure both programs were using the correct port. Once I corrected the issue, I was able to submit a purchase successfully and receive a confirmation message.
What surprised me most was how the GUI and API worked together even though they were separate programs. This assignment helped me better understand JSON, HTTP POST requests, client-side validation, and how different systems communicate. I would like to learn more about storing submitted purchase information in a database.
